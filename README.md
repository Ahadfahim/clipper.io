# Clipper.io

Agent-run clipping system for the Vyro and Whop Content Rewards marketplaces. It is installed Windows desktop software, driven by Claude Code agents.

- [PLAN.md](PLAN.md): architecture and phases (source of truth)
- [UI.md](UI.md): the desktop UI (Windows utility style)
- [CLAUDE.md](CLAUDE.md): rules for Claude Code sessions in this repo
- [docs/ENVIRONMENT.md](docs/ENVIRONMENT.md): the target machine
- [handoff/CLOUD_PROMPT.md](handoff/CLOUD_PROMPT.md): master prompt for the cloud build session
- `HANDOFF.md` (created by the cloud session): what was built, and what the local session does next
